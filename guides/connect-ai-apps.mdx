title: Connect AI apps
description: Add Rowsafe to ChatGPT, Claude, Cursor, VS Code, Codex or Windsurf. Sign in with Rowsafe once; no API key to create or paste.
---

Ask your AI app "Are my databases backed up?", "Why is the orders database slow today?" or "What should I fix first?", and let coding agents save a [Mark](/docs/concepts/restore-points) before a risky change. Apps connect to Rowsafe's MCP server at:

```text
https://api.rowsafe.sh/mcp
```

The first time, the app opens Rowsafe in your browser. You pick the organization, choose whether the app may save Marks and whether it may **Act for you**, and click **Allow**. That's it: no API key to create or paste. (Prefer a key, for CI or an app without sign-in? Use the **Remote endpoint** setup in the [MCP reference](/docs/reference/mcp#set-up).) The dashboard has the same steps, with one-click install links for Cursor and VS Code, under **Ask your AI**.

## What a connected app can do

| | Connected app |
|---|---|
| See databases, health scores and findings, backups, Proof results, Marks, slow-query trends | Yes |
| Alerts, what's running now, metrics, disk forecast, uptime, security, updates, the audit log, approval requests | Yes |
| [Rowsafe Cloud](/docs/guides/rowsafe-cloud) sizes and prices, and your Rowsafe Cloud servers | Yes |
| Save a Mark (a named moment you can rewind to) | Only if you ticked **Save Marks** |
| Run backups, Proof and checks, preview migrations, make masked safe copies, acknowledge alerts, change schedules | Only if you ticked **Act for you** |
| Ask you to approve a change to production (apply a fix, restart, restore, rewind, upgrade, ...) | Only if you ticked **Act for you**. Nothing changes until an owner or admin clicks **Approve** in the dashboard; see [Approvals](/docs/guides/approvals) |
| Ask you to approve a new Rowsafe Cloud server, a new size, a clone or deleting one, and a database and login for the app it's building | Only if you ticked **Act for you**. You see the price and click **Approve and pay**; see [Need a database?](/docs/guides/ai-agents#need-a-database) |
| Approve a change, or restore, rewind, restart or apply a fix by itself | Never |
| Pay, or see the password of a database it asked for | Never: an owner pays, and the password is shown only to the person who approves (who can give it to the app) |
| Read the rows in your tables | Never: Rowsafe itself never sees them |

Apps act for one organization, the one you picked. Everything they do is in the [audit log](/docs/guides/teams#audit-log), attributed to the app, and Marks they save show the app as their creator.

## Set it up

<Tabs items={["ChatGPT", "Claude", "Cursor", "VS Code", "Codex", "Windsurf"]}>
<Tab value="ChatGPT">

1. In ChatGPT, open **Settings**, **Apps & Connectors**, **Advanced settings**, and turn on **Developer mode**. It's available on paid plans; in a Business or Enterprise workspace an admin may need to allow it.
2. Click **Create**. Name it **Rowsafe**, paste `https://api.rowsafe.sh/mcp`, and choose **OAuth**.
3. Sign in with Rowsafe and click **Allow**.
4. In a new chat, click **+**, pick Rowsafe, and ask away.

Rowsafe isn't in ChatGPT's app directory yet; until it is, it's added this way.

</Tab>
<Tab value="Claude">

**claude.ai, Claude Desktop and mobile:**

1. Open **Settings**, **Connectors**, and click **Add custom connector**.
2. Name it **Rowsafe** and paste `https://api.rowsafe.sh/mcp`. On a Team or Enterprise plan, an owner adds it once for the organization; then everyone connects it for themselves.
3. Click **Connect**, sign in with Rowsafe and click **Allow**.

**Claude Code:**

```sh
claude mcp add --transport http rowsafe https://api.rowsafe.sh/mcp
```

Then run `/mcp` in Claude Code and choose **Authenticate**. For Marks saved automatically before migrations, add the [Rowsafe plugin](/docs/guides/ai-agents) too.

</Tab>
<Tab value="Cursor">

1. In the Rowsafe dashboard, open **Ask your AI**, **Cursor**, and click **Add to Cursor**. Or add it to `~/.cursor/mcp.json` yourself:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "rowsafe": { "url": "https://api.rowsafe.sh/mcp" }
     }
   }
   ```

2. In **Cursor Settings**, **MCP**, click **Needs login** next to Rowsafe.
3. Sign in with Rowsafe and click **Allow**.

</Tab>
<Tab value="VS Code">

1. In the Rowsafe dashboard, open **Ask your AI**, **VS Code**, and click **Add to VS Code**. Or add it to `.vscode/mcp.json` (or your user configuration):

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "rowsafe": { "type": "http", "url": "https://api.rowsafe.sh/mcp" }
     }
   }
   ```

2. When the server starts, VS Code asks whether Rowsafe may sign in. Click **Allow**.
3. Sign in with Rowsafe and click **Allow**. Use it from Copilot Chat in agent mode.

</Tab>
<Tab value="Codex">

```sh
codex mcp add rowsafe --url https://api.rowsafe.sh/mcp
codex mcp login rowsafe
```

Your browser opens Rowsafe: sign in and click **Allow**.

</Tab>
<Tab value="Windsurf">

1. In the Cascade panel, open the **…** menu, then **MCP servers** and **View raw config**.
2. Add Rowsafe inside `mcpServers`, save and refresh:

   ```json title="mcp_config.json"
   {
     "mcpServers": {
       "rowsafe": { "serverUrl": "https://api.rowsafe.sh/mcp" }
     }
   }
   ```

3. Sign in with Rowsafe and click **Allow**.

</Tab>
</Tabs>

Any other app that supports remote MCP servers with OAuth works the same way: give it the URL.

## Who can connect an app

Owners and admins of an organization. A member who tries sees the request, but **Allow** is off; an admin can connect the app, or make them an admin.

## Disconnect an app

In the dashboard, open **Settings**, **Connected apps**, and click **Disconnect**. The app loses access right away; Marks it saved stay. Rowsafe also disconnects an app by itself when:

- the person who allowed it is removed from the organization;
- a sign-in token is used twice, which means it may have leaked. Connect the app again if it was yours.

## How it stays safe

- **You approve every app**, on a Rowsafe page, in the browser where you're signed in. The page shows the app's name, and whether Rowsafe could verify it: ChatGPT and Claude Code publish their identity on their own domain (shown as **Verified: chatgpt.com**); other apps only give a name, marked **not verified**. It also shows where you'll return to, and warns when an app runs on your own computer.
- **Only known apps and apps on your own computer can receive a sign-in.** Rowsafe sends approvals only to the published callback addresses of ChatGPT, Claude, VS Code and Cursor, and to `localhost`. A link someone sends you can't send your approval to their website, and only the browser that started a sign-in can finish it.
- **Short-lived tokens, only for MCP.** An app gets a one-hour access token that works on `https://api.rowsafe.sh/mcp` and nowhere else, and a refresh token that works once. Rowsafe stores only their hashes.
- **Nothing beyond what you ticked.** Without **Act for you**, an app never sees the tools that queue backups, make copies or ask for changes, and the API refuses those actions for it too. With it, changes to production are still only requests that a person approves; an app can never approve one.

This follows the [MCP authorization specification](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization) (OAuth 2.1 with PKCE, protected resource metadata, client ID metadata documents and dynamic client registration). Details are in the [MCP server reference](/docs/reference/mcp#sign-in-with-rowsafe-oauth).

## Troubleshooting

- **"We don't know this app" or "Rowsafe only sends sign-ins back to known AI apps":** the app asked Rowsafe to return somewhere other than a known AI app or `localhost`. Tell us which app it is at hello@rowsafe.sh, or use an [API key](/docs/reference/mcp#set-up) with it instead.
- **"Finish in the browser you started in":** the sign-in was opened in another browser (or the link was forwarded). Start again from the app, in one browser.
- **"This sign-in expired":** sign-ins last 10 minutes. Start again from the app.
- **The app keeps asking you to sign in:** it was disconnected (see above), or it didn't keep its refresh token. Connect it again.
- **Allow is greyed out:** you're a member of that organization; ask an admin.
