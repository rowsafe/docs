---
title: Connect Hetzner
description: Give Rowsafe a Hetzner Cloud API token for one project so it can create database servers there.
---

To [create servers for you](/docs/guides/create-a-server) in Hetzner Cloud, Rowsafe needs an **API token for one project**. It takes about two minutes.

## Create the token

<Steps>
<Step>

### Open a project just for Rowsafe

Sign in to [Hetzner Cloud](https://console.hetzner.cloud) and create a project for your databases. A token reaches everything in its project, so a project of its own keeps your other servers out of reach.

</Step>
<Step>

### Generate the token

In the project, open **Security**, then **API tokens**, and click **Generate API token**. Name it `Rowsafe`, choose **Read & Write**, and generate it. Copy it now: Hetzner shows it only once.

</Step>
<Step>

### Paste it into Rowsafe

In the dashboard, open **Settings → Cloud accounts** (or **Create a server for me**) and click **Connect a cloud account**. Choose **Hetzner Cloud**, paste the token into **API token**, name the account and click **Connect**.

</Step>
</Steps>

Rowsafe checks the token first, without creating anything that costs money. A **Read**-only token is refused.

## What access this gives Rowsafe

**Read & Write on one project.** Hetzner can't limit a token further, which is why the project should be Rowsafe's alone.

Rowsafe only touches what it creates, all labelled `rowsafe=1`:

- **servers** (Debian 12), only when someone clicks and confirms;
- **firewalls**, one per server, letting in only your addresses;
- **SSH keys**, only the ones you give it. Never its own.

See [what Rowsafe does with your cloud account](/docs/guides/create-a-server#what-rowsafe-does-with-your-cloud-account).

## Revoke it

- **In Hetzner:** project, **Security**, **API tokens**: delete the `Rowsafe` token. It stops working at once.
- **In Rowsafe:** **Settings → Cloud accounts**, **Remove** (once its servers are deleted). Nothing in Hetzner changes.

Your servers keep running and stay protected. Resize, firewall changes and deletes then happen in the Hetzner console.

## Good to know

- Prices are Hetzner's own, shown "from" (cheapest location, before VAT). Your Hetzner bill is what counts.
- If you reach Hetzner's server limit, Rowsafe says so: ask Hetzner to raise it, or delete a server.
- To check the token, Rowsafe creates an empty, free firewall (`rowsafe-token-check-…`) and deletes it right away.
