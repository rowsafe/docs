---
title: Connect AI apps
description: Add Rowsafe to ChatGPT, Claude, Cursor, VS Code, Codex or Windsurf by signing in once, with no API key.
---

Ask your AI app "Are my databases backed up?" or "What should I fix first?", and let coding agents save a [Mark](/docs/concepts/restore-points) before risky changes. Apps connect to:

```text
https://api.rowsafe.sh/mcp
```

The first time, the app opens Rowsafe in your browser. Pick the organization, tick **Save Marks** and **Act for you** if you want them, and click **Allow**. No API key needed. (For CI or an app without sign-in, use an [API key](/docs/reference/mcp#set-up).)

## What a connected app can do

| | Connected app |
|---|---|
| See databases, health, findings, backups, Proof, Marks, alerts, metrics, security, updates, the audit log, Rowsafe Cloud prices and servers | Yes |
| Save a Mark | With **Save Marks** |
| Run backups, Proof and checks, preview migrations, make masked safe copies, acknowledge alerts, change schedules | With **Act for you** |
| Change production (fix, restart, restore, rewind, upgrade, ...) and Rowsafe Cloud servers | With **Act for you**: as you, right away, while you're an owner or admin ([How AI agents act](/docs/guides/agent-autonomy)) |
| Create a database and login for its app | Never: you create it in the dashboard, where your browser makes the password. A local `rowsafe mcp` can, on PostgreSQL ([Need a database?](/docs/guides/ai-agents#need-a-database)) |
| Change what AI agents may do | Never: only an owner, in the dashboard |
| Pay | Never: a first payment is an owner's, at a checkout link the app gives you |
| Read the rows in your tables | Never: Rowsafe itself never sees them |

An app acts for the one organization you picked. Everything it does is in the [audit log](/docs/guides/teams#audit-log) as you through the app.

## What the Allow page says

With **Act for you**, the page explains that the app can make the changes you can make in the dashboard, right away, and confirms disruptive ones with you in chat. If you stop being an owner or admin, its changes are refused. Leave it unticked for an app that should only look.

### Apps connected earlier

Older apps show **Can't make changes yet** in **Settings → Connected apps**. The person who connected one clicks **Let it act as me**, or connects it again. Until then, Rowsafe refuses its changes.

## Set it up

<Tabs items={["ChatGPT", "Claude", "Cursor", "VS Code", "Codex", "Windsurf"]}>
<Tab value="ChatGPT">

1. In ChatGPT, open **Settings**, **Apps & Connectors**, **Advanced settings**, and turn on **Developer mode**. It needs a paid plan; in a Business or Enterprise workspace an admin may need to allow it.
2. Click **Create**. Name it **Rowsafe**, paste `https://api.rowsafe.sh/mcp`, and choose **OAuth**.
3. Sign in with Rowsafe and click **Allow**.
4. In a new chat, click **+**, pick Rowsafe, and ask away.

Rowsafe isn't in ChatGPT's app directory yet, so it's added this way.

</Tab>
<Tab value="Claude">

**claude.ai, Claude Desktop and mobile:**

1. Open **Settings**, **Connectors**, and click **Add custom connector**.
2. Name it **Rowsafe** and paste `https://api.rowsafe.sh/mcp`. On a Team or Enterprise plan, an owner adds it once for the organization; then everyone connects it for themselves.
3. Click **Connect**, sign in with Rowsafe and click **Allow**.

**Claude Code:**

```sh
claude mcp add --transport http rowsafe https://api.rowsafe.sh/mcp
```

Then run `/mcp` in Claude Code and choose **Authenticate**. For Marks saved automatically before migrations, add the [Rowsafe plugin](/docs/guides/ai-agents) too.

</Tab>
<Tab value="Cursor">

1. In the Rowsafe dashboard, open **Ask your AI**, **Cursor**, and click **Add to Cursor**. Or add it to `~/.cursor/mcp.json`:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "rowsafe": { "url": "https://api.rowsafe.sh/mcp" }
     }
   }
   ```

2. In **Cursor Settings**, **MCP**, click **Needs login** next to Rowsafe.
3. Sign in with Rowsafe and click **Allow**.

</Tab>
<Tab value="VS Code">

1. In the Rowsafe dashboard, open **Ask your AI**, **VS Code**, and click **Add to VS Code**. Or add it to `.vscode/mcp.json` (or your user configuration):

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "rowsafe": { "type": "http", "url": "https://api.rowsafe.sh/mcp" }
     }
   }
   ```

2. When the server starts, VS Code asks whether Rowsafe may sign in. Click **Allow**.
3. Sign in with Rowsafe and click **Allow**. Use it from Copilot Chat in agent mode.

</Tab>
<Tab value="Codex">

```sh
codex mcp add rowsafe --url https://api.rowsafe.sh/mcp
codex mcp login rowsafe
```

Your browser opens Rowsafe: sign in and click **Allow**.

</Tab>
<Tab value="Windsurf">

1. In the Cascade panel, open the **…** menu, then **MCP servers** and **View raw config**.
2. Add Rowsafe inside `mcpServers`, save and refresh:

   ```json title="mcp_config.json"
   {
     "mcpServers": {
       "rowsafe": { "serverUrl": "https://api.rowsafe.sh/mcp" }
     }
   }
   ```

3. Sign in with Rowsafe and click **Allow**.

</Tab>
</Tabs>

Any other app that supports remote MCP servers with OAuth works the same way: give it the URL.

## Who can connect an app

Owners and admins. A member sees **Allow** greyed out: an admin connects the app, or makes them an admin.

## Disconnect an app

**Settings → Connected apps**, **Disconnect**. Access ends right away; Marks it saved stay.

Rowsafe also disconnects an app when the person who allowed it is removed, leaves the organization or deletes their account, or when a sign-in token is used twice (it may have leaked; connect again if it was yours).

## How it stays safe

- **You approve every app** on a Rowsafe page, in your own browser. It shows the app's name, whether Rowsafe could verify it (ChatGPT and Claude Code show **Verified: chatgpt.com** and similar; others are **not verified**), where you'll return to, and a warning when the app runs on your own computer.
- **Sign-ins go only to known apps.** Rowsafe sends approvals only to the published callback addresses of ChatGPT, Claude, VS Code and Cursor, and to `localhost`. A link someone sends you can't route your approval to their website, and only the browser that started a sign-in can finish it.
- **Short-lived tokens, for MCP only:** a one-hour access token for `https://api.rowsafe.sh/mcp` and a single-use refresh token. Rowsafe stores only their hashes.
- **Never more than you ticked, or more than you.** Without **Act for you**, the app never sees the tools that run backups, make copies or change production, and the API refuses them. With it, Rowsafe checks your role at every change, with the dashboard's own checks and Marks ([safety nets](/docs/guides/agent-autonomy#safety-nets-that-stay-on)).

It follows the [MCP authorization specification](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization) (OAuth 2.1 with PKCE, protected resource metadata, client ID metadata documents, dynamic client registration). Details: [MCP reference](/docs/reference/mcp#sign-in-with-rowsafe-oauth).

## Troubleshooting

- **"We don't know this app" or "Rowsafe only sends sign-ins back to known AI apps":** the app wants to return somewhere unknown. Tell us which app at hello@rowsafe.sh, or use an [API key](/docs/reference/mcp#set-up).
- **"Finish in the browser you started in":** start again from the app, in one browser.
- **"This sign-in expired":** sign-ins last 10 minutes. Start again.
- **The app keeps asking you to sign in:** it was disconnected, or lost its refresh token. Connect it again.
- **Allow is greyed out:** you're a member. Ask an admin.
